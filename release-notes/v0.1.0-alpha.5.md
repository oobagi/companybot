## What's new
- **See what agents did.** Settings → Activity lists every action an agent took in chats you can see, like saving a memory or updating a record. Only the person the agent was helping can see what came back. (#15)
- **Look inside any tool step.** Click a line like "Used memory_remember" in a reply to see exactly what the agent sent and what it got back. (#15)
- **Pick your time zone.** Your preferences now has a Time zone setting. It's Automatic by default, so it follows your computer. (#16)

## Improvements
- **Memories show when an agent saved them.** For example, "Jaden, via agent". (#15)

## Fixes
- **Agents tell time in your time zone.** Asking for the time no longer gets a UTC answer that can land on the wrong day. (#16)
