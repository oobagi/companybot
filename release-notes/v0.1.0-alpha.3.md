Alpha build — expect rough edges.

## What's new
- **Team chat.** Channels (everyone starts in #general), direct messages with teammates, threads and emoji reactions. Your earlier agent conversations move into each agent's DM. (#9)
- **Agents as teammates.** @mention an agent in a channel or thread and it replies right there. In its own DM it answers every message, and it can react to the message that asked for it. (#9)
- **Automations.** Install ready-made jobs from Customize → Automations, like a Morning brief every weekday at 8am. Each run lands in your DM with the agent. (#10)
- **See what each reply cost.** Under every reply: the model, how long it took, how much it used and what it cost, plus a running total. (#8)

## Improvements
- **Every agent, plugin, skill and automation has its own screen**, with a back link, and the back button works. (#10)
- **Long conversations stay quick.** Older messages fold into a summary, so replies stay fast and cheap. (#8, #9)
- **Connected services cost less to use.** Agents only look up a service's tools when they need them. (#9)
- **Privacy in shared chats.** In channels and group chats, agents only use team memories, never anyone's personal ones. (#9)

## Fixes
- Inviting someone who's already in the workspace now says so instead of silently doing nothing. (#7)
- Links in replies only open web pages and email. (#7)
